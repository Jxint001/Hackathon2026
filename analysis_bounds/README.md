# AI 辅助的加速比分析与构造

本目录保留两项探索成果，输入和评测工具分别使用仓库的 `data/` 与 `code/`。

1. **加速比上界**：[上界汇总](current_upper_table/README.md)。让 AI 分析计算依赖、管道负载、必要 DDR 搬运与内存容量，推导执行时间下界，再换算加速比上界；保留分析脚本、证明与复核证书。
2. **高加速比构造**：[案例汇总](examples/README.md)。让 AI 针对部分计算图设计并搜索分核与排序方案，保留五个已通过官方评测的最终 plan、构造说明与结果摘要。

```text
analysis_bounds/
├── README.md
├── current_upper_table/    # 上界表、分析脚本与专项证书
└── examples/               # case03、05、07、08、09 的最终构造
```

统一采用默认单核时间作为加速比分子；理论上界表示分析允许的极限，构造结果表示已经达到的性能。这些专项探索结果与 `npu_scheduler/` 的通用算法成绩分开记录。
