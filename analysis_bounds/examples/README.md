# AI 辅助构造的高加速比调度例子

保留五个已由官方评测器验证的最终 plan。AI 根据具体图分析复用关系、设计分核与执行顺序，再通过搜索和评测改进方案；这些记录独立于最终 C++ 程序的统一成绩。

加速比的分子是同版本官方评测器生成的默认单核时间。所有方案使用五核接口，case03 实际启用四核。

| 用例 | 默认单核 cycles | 方案 cycles | 实测加速比 | 构造与复现 |
| --- | ---: | ---: | ---: | --- |
| case_03 | 6,295,267 | 1,765,086 | 3.56654973× | [说明与 plan](case03_5cores_current/README.md) |
| case_05 | 18,876,779 | 5,019,326 | 3.76081948× | [说明与 plan](case05_5cores_current/README.md) |
| case_07 | 6,340,434 | 1,481,714 | 4.27912134× | [说明与 plan](case07_5cores_current/README.md) |
| case_08 | 15,419,076 | 3,460,060 | 4.45630307× | [说明与 plan](case08_5cores_current/README.md) |
| case_09 | 6,794,313 | 1,740,017 | 3.90473944× | [说明与 plan](case09_5cores_current/README.md) |

每个案例保留构造思路、最终 plan 和带哈希的评测摘要；完整评测结果与时间线可按案例说明重新生成。case05 另保留配方及生成脚本。

已达到的加速比与[理论上界](../current_upper_table/README.md)分别报告；这些例子不构成最优性证明。
