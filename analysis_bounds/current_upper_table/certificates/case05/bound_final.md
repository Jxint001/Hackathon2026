# case05 五核加速比：严格上界 4.56417×

当前 `data/case_05.json`、固定评测器、L1=1.5 MiB、UB=128 KiB、共享DDR=60 bytes/cycle、跨核等待1000 cycles下：

\[
T_5\ge4,135,868,\qquad
S_5\le\frac{18,876,779}{4,135,868}=4.56416379826\ldots
\]

基线为当前 `singlecore_evaluate.py` 默认调度的18,876,779 cycles。
结论覆盖任意合法五核划分、单op子图重排、跨核拆链与spill。
这是所有方案的上界，不是已构造方案的实测加速比；目前仍未排除4.5×或4×。

## 1. 基本数据和缓存边界

以32 KiB为一单位。case05是32×48×12乘加网格，共N=18,432个计算，每个PIPE_M操作1024 cycles；C=1,536条长度12的输出链。A/B输入和最终结果各一单位，中间部分和两单位。

Step2软阈值43.2单位；当前操作保护的数据至多六单位，故计算前驻留量至多43。普通累加完成释放旧部分和两单位，计算后至多41；首项乘法允许43。
当前A、B共占两单位。因此计算后的**部分和驻留量至多39**，首项乘法允许41。若某个A/B恰在此处最后使用，其释放同步减小总容量，不改变部分和上限39。

最终计算与其唯一COPY_OUT在reverse DFS中相邻，二者同子图，稳定分桶排序保持相邻。切点放在该COPY_OUT后，可再扣一单位最终结果。
令d为该计算最后使用的本核A/B输入数量，则内部切点总容量上界为：

\[
b\le41+2\mathbf1_{\rm root}-d-\mathbf1_{\rm final}.
\]

## 2. 用12层计数描述任意一段

把每核计算序列分段，令n_k为段内归约层k的操作数，t=Σn_k。
同一输出链连续归约层都属于同一“核、段”时，构成一个连续片段；离开再返回要重新计数。片段数r满足：

\[
r\ge b(n):=n_0+\sum_{k=1}^{11}(n_k-n_{k-1})_+\ge c:=\max_k n_k.
\]

该层不同A/B输入数至少f(n_k)=⌈2√n_k⌉，因为a_kb_k≥n_k。记D=Σf(n_k)。
一段有r−n₀个需要旧部分和的片段入口、r−n₁₁个非最终片段出口。因此它们的体积分别至少：

\[
P_{\rm in}=2(r-n_0),\qquad P_{\rm out}=2(r-n_{11}).
\]

每个出口张量都是不可覆盖的独立版本，下一个计算消费者在段外；它必须留在缓存或写回DDR。

## 3. 额外计入无法藏在缓存中的部分和读取

记A为全部A/B读取量，W为全部部分和/最终结果写出量，R为全部部分和读取量，Q=A+W+R。
每个真实中间部分和写出都必须有后续读回：普通spill有对应SPILL_IN，跨核COPY_OUT有接收核COPY_IN；若两次写出，分别对应两次读取。
因此R至少为全部中间部分和写出量，也至少为跨核链边数E的两倍。

取δ=151/163。将δR的一半用于入口读取下界，另一半用于出口写回所必需的后续读取；剩余(1−δ)R单独下界为2(1−δ)E。这样不会重复计算同一次读取。

设段首/末A/B驻留体积为x_s/x_e，部分和驻留为z_s/z_e，则：

\[
A_{\rm 段}\ge D-x_s,\quad
W_{\rm 段}\ge2r-n_{11}-z_e,
\]
\[
R_{\rm 段}\ge[P_{\rm in}-z_s]_+,
\quad W_{\rm 中间,段}\ge[P_{\rm out}-z_e]_+.
\]

写`z_e=b_e−x_e`，跨段求和时`x_s−x_e`抵消，基础项只需扣一次内部总容量。
再用普通边界的z≤39，以及r≥c，额外读惩罚可保守取为：

\[
\frac\delta2\{[2(c-n_0)-39]_++[2(c-n_{11})-39]_+\}.
\]

一个首项乘法边界使总容量多两单位；它还分别影响前段出口和后段入口惩罚，合计最多额外2δ。因此每个首项乘法切点总共补偿2(1+δ)。A/B和最终结果释放至少保留原来的每单位容量收益。

## 4. 精确整数动态规划

使用固定权重θ，其分母为1,630,000，分子依次为：

```text
1034132, -57415, 481038, -62964, -62964, 298172,
298172, -62964, -62964, 481038, -57415, 1034134
```

Σθ=2。定义：

\[
G(t)=\min_{\sum n_k=t}\left\{
\sum f(n_k)+2b(n)-\sum\theta_kn_k
+\frac\delta2([2(c-n_0)-39]_++[2(c-n_{11})-39]_+)
\right\}.
\]

每个归约层全图都有C个操作，权重项总和为2C；最终结果比两单位少一单位，修正总共C。因此全局常数为+C。
程序只枚举12个整数层计数的DP状态，不枚举原图调度。具体枚举峰值上限c=0…163，要求每层n≤c；在首层、末层分别加上述惩罚。惩罚随c单调，最小化后等价于c=max n。

中间层递推为：

\[
DP_k(s,n)=f(n)-\theta_kn+
\min_m\{DP_{k-1}(s-n,m)+2(n-m)_+\}.
\]

全部乘1,630,000后用整数运算；G(163)=152719708/1630000。
一个独立C++程序逐一枚举前驱m，已核对全部G(0)…G(163)，与搜索程序的优化DP完全一致。

## 5. 全部163种切分偏移取平均

令q=163。对n≥q个计算的核心，q种等间隔切分偏移的G项平均为：

\[
[(n-q+1)G(q)+2\sum_{r=1}^{q-1}G(r)]/q.
\]

每个内部位置成为切点的概率为1/q。忽略A/B和最终结果的释放收益时，五核下界为：

\[
B=\frac{N(G(q)-41)+5[-(q-1)G(q)+2\sum_{r=1}^{q-1}G(r)+41]}q
+C-\frac{2(1+\delta)C}{q}.
\]

## 6. 用负载限制补上输入释放收益

若T≥337×12×1024=4,141,056，已经超过待证下界。以下只考虑T<该值，此时每核完整留住的输出链数h_p≤336。

跨核链边数为E时，至多E条链被拆分，所以Σh_p≥1536−E。
五核完整链的输入投影满足以下小规模整数DP：

\[
12\min\{\sum f(h_p):0\le h_p\le336,\ \sum h_p=1536\}=2100.
\]

由于f(h+1)−f(h)≤2，将不足的链逐条补齐，每补一条至多增加24个A/B输入。因此实际不同本核A/B输入数D_tot≥2100−24E。
每个输入在本核最后使用时释放一单位。最多每核两个释放发生在最后一个计算位置，故内部切点至少提供D_tot−10个输入释放；最终结果至少提供C−5=1531个释放。

δ=1−12/q恰使跨核读取项抵消E：

\[
2(1-\delta)E+\frac{D_{\rm tot}-10}{q}\ge\frac{2090}{q}.
\]

于是：

\[
Q\ge B+\frac{1531+2090}{163}
=\frac{502982999519}{66422500}.
\]

搬运为整数单位，故Q≥7573，即至少248,152,064 bytes；共享带宽给出T≥⌈248,152,064/60⌉=4,135,868。
这小于前面的分支阈值4,141,056，故两种情况都成立。
若某核不足163个计算，其他四核至少一核承担4568个计算，仅PIPE_M就需4,677,632 cycles，仍更强。
