# case03 五核加速比上界：4.28194×

当前数据与评测设置下，固定单核基线为 **6,295,267 cycles**。可以严格证明：

\[
T_5\ge1,470,191,\qquad
S_5\le6,295,267/1,470,191=4.28193819715\ldots
\]

此结论覆盖任意合法分核、单 op 子图顺序、跨核拆分归约链，以及空闲核。
它是理论上界，不是已经构造出的加速比。使用 L1=1.5 MiB、UB=128 KiB、DDR=60 bytes/cycle、跨核等待1000 cycles。

## 1. 计算图与容量

以32 KiB为一单位。case03是8×24×32乘加网格，共6144个PIPE_M计算，每个1024 cycles；有192条长度32的输出链。
A/B输入各一单位，中间部分和两单位，最终输出一单位。每个中间部分和只有一个计算消费者；共有1024个不同的原始A/B输入。

Step2先分配、检查容量，再执行和释放。软阈值为43.2单位，当前计算保护的数据最多六单位，故计算前至多驻留43单位。
普通累加释放旧部分和两单位，计算后至多41单位；首项乘法允许43。
当前A/B占两单位，因此普通边界的部分和容量至多39，首项边界允许41。A/B最后使用时的释放不会增大这个39上限。

最终计算与唯一COPY_OUT在默认reverse DFS中相邻，同属一个子图，稳定分桶排序保留相邻；切点放在COPY_OUT后。
令d为该计算最后使用的本核A/B数量，则内部切点的总容量满足：

\[
b\le41+2\mathbf1_{\rm root}-d-\mathbf1_{\rm final}.
\]

## 2. 任意一段的搬运下界

对某核的一段计算，记nₖ为该段第k个归约层的计算数，t=Σnₖ，c=max nₖ。
同一输出链在同一“核、段”里的连续归约层构成片段。实际片段数r满足：

\[
r\ge b(n):=n_0+\sum_{k=1}^{31}(n_k-n_{k-1})_+\ge c.
\]

每层有nₖ个不同的行列组合，故不同A/B数至少f(nₖ)=⌈2√nₖ⌉；D=Σf(nₖ)。
片段入口需要的旧部分和体积为2(r−n₀)，非最终片段出口为2(r−n₃₁)。

设边界驻留A/B体积为x，部分和为z。该段A/B读取至少D−x_start，输出写出至少2r−n₃₁−z_end。
跨段求和时，x_start和x_end抵消，只需扣除内部切点总容量。

此外，部分和读取R既不小于各段入口无法缓存的量，也不小于各段中间出口无法缓存的量：每个中间写出必须有后续读回，包括跨核复制。
取这两个下界的平均，可额外计入：

\[
\tfrac12\{[2(c-n_0)-39]_++[2(c-n_{31})-39]_+\}.
\]

首项乘法切点使基础容量多两单位，且影响相邻两段的入口/出口惩罚，合计最多再多两单位。因此每个首项切点统一扣四单位。
这个推导没有要求一条输出链全部放在同一核。

## 3. 固定权重的精确动态规划

取每层θₖ=1/16，Σθₖ=2，定义：

\[
G(t)=\min_{\sum n_k=t}\left\{
\sum f(n_k)+2b(n)-t/16
+\tfrac12([2(c-n_0)-39]_++[2(c-n_{31})-39]_+)
\right\}.
\]

程序枚举峰值上限c及32层计数，状态为“已用计算总数、上一层计数”；不是枚举调度方案。
递推为：

\[
DP_k(s,n)=f(n)-n/16+\min_m\{DP_{k-1}(s-n,m)+2(n-m)_+\}.
\]

在首尾层加入相应惩罚；全部乘16后是整数运算。
精确证书保存G(0)…G(180)，其中 **G(180)=1764/16=110.25**。
独立C++实现逐一枚举前驱m，已核对全部181个值。

## 4. 平均切分并合并所有核心

取q=180，对每核的q种等间隔切分偏移取平均。若该核有n≥q个计算，G项减去普通内部边界容量后的平均为：

\[
F(n)=\frac{n(G(q)-41)-(q-1)G(q)+2\sum_{r=1}^{q-1}G(r)+41}{q}
=\frac{277}{720}n+\frac{1067}{40}.
\]

每个内部位置成为切点的概率为1/q。全图每层192个计算，权重抵消带来2×192；最终输出由两单位改为一单位，减192，净增192。
首项切点最多192个，扣4×192/q。
至少192−5个最终释放，以及1024−2×5个A/B最后使用释放，发生在内部位置。
因此当五核都至少有180个计算时，总DDR搬运单位数Q满足：

\[
Q\ge\frac{277}{720}\cdot6144+5\cdot\frac{1067}{40}
+192+\frac{1024-3\cdot192-3\cdot5}{180}
=\frac{193789}{72}.
\]

搬运量是整数单位，所以至少2692单位，即88,211,456 bytes；共享带宽给出T≥⌈88,211,456/60⌉=1,470,191。

若某核不足180个计算，其他四核至少有一核承担⌈(6144−179)/4⌉=1492个计算，仅PIPE_M就需1,527,808 cycles，更强。
因此上述上界也覆盖短核和空闲核。
