# case08：当前能严格复核的通用上界

对当前图、固定单核基线15,419,076 cycles及五核，已证明

\[
T_5\ge2,419,734,\qquad S_5\le6.3722194258.
\]

**这个界仍然很松，不能排除4.8×。** 现有构造的搬运量不能作为任意合法方案的搬运下界。

证明先放宽跨核复制、内存容量及额外spill，只保留原计算依赖、每个外部输入的一次必需读取和最终输出的一次必需写回。
所有计算保留原来的pipe和cycles，DDR搬运保留官方评测器采用的独占带宽工作量。
放宽约束只可能使问题更容易，所以该模型的下界适用于原问题，允许任意分核和单op重排。

从该DAG的最长路计算每个操作最早开始下界r和完成后的最短尾部q。
找出6384个PIPE_M操作，它们均满足r≥8281、q≥581，合计计算量12,054,360 cycles。
任意五核调度中，这些操作都必须完整落在时间窗[8281,T−581]内，而五条PIPE_M的总服务率至多5：

\[
5(T-8281-581)\ge12,054,360,
\quad T\ge8281+\lceil12,054,360/5\rceil+581=2,419,734.
\]

证书见`structure_upper_certificate.json`。复核使用`analysis_bounds/current_upper_table/dag_bounds.py`中的`compute_bounds(graph,60,(5,),ancestor_work=False)`。


case05的三维矩阵投影证书不能直接用于本例：这里含滑动卷积、长残差、多写者及多个计算管道。
要进一步压到4.8×以下，需要另证至少约192.74MB的必要DDR搬运或更强的联合资源下界；本文件没有作此声称。
