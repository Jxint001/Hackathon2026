# 两核简化图演示案例

保留两张简化图的固定回放数据，统一使用核 0、核 1。初始与最终方案均使用两核。

| 用例 | 计算操作数 | 初始子图数 | 初始 cycles | 最终 cycles | 案例说明 |
| --- | ---: | ---: | ---: | ---: | --- |
| case_05 矩阵乘加 | 27 | 9 | 27,100 | 24,606 | [结构与搜索结果](case05_2cores/README.md) |
| case_08 卷积与向量 | 26 | 14 | 24,575 | 23,458 | [结构与搜索结果](case08_2cores/README.md) |

小图保留原计算操作的类型、管道、周期与张量大小，在截断处补入 COPY / DDR 边界；不是完整用例的等价缩放。时间与搬运量是已保存的评估结果，网页不会重新计算。

每例的 `playback.js` 是纯数据，包含简化 DAG、连续命名、分组与初始化记录、所选搜索候选、前后方案和最终结果；矩阵案例另含网格与分块对应关系。

从 [演示入口](../index.html) 选择用例，使用方式见 [demo 说明](../README.md)。
