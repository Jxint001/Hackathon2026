# case05 两核演示：矩阵乘加

从原 case_05 保留 3×3 输出网格，每格对应一条三级乘加链，共 27 个计算操作。行、列之间共享输入；短链合并后形成 9 个初始子图。网格是同一批 DAG 操作的结构视图，不还原矩阵数值。

| 指标 | 初始方案 | 最终方案 |
| --- | ---: | ---: |
| 完成时间 / cycles | 27,100 | 24,606 |
| 搬运量 / bytes | 1,572,864 | 1,474,560 |
| 活动核数 | 2 | 2 |

局部搜索回放两个阶段：

1. **数据局部性 · 网格分块与重排**：展示分块、遍历与分核候选，接受结果依次为 26,384、26,247、24,911、24,606 cycles。
2. **计算均衡 · 链迁移**：展示后续迁链尝试；本例主起点没有进一步改善，保留 24,606 cycles。
