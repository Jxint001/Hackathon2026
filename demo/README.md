# 多核调度算法演示

用 AI 编写的算法演示网站demo，采用矩阵乘法与卷积的两个例子，即 case_05、case_08 的两张简化图，演示 DAG 分组、初始解构造和局部搜索。统一使用两核，操作和张量分别按 `op_1…`、`tensor_1…` 连续命名。

直接用浏览器打开 [index.html](index.html)，无需安装依赖、编译或启动服务。网页读取已保存的方案与评估结果，只做步骤回放和绘图，不运行调度、搜索或性能模拟。

```text
demo/
├── README.md
├── index.html                 # 离线演示入口
├── assets/                    # 展示脚本与样式
│   ├── app.js
│   └── style.css
└── examples/                  # 两核简化案例的说明与固定回放数据
    ├── README.md
    ├── case05_2cores/
    │   ├── README.md
    │   └── playback.js
    └── case08_2cores/
        ├── README.md
        └── playback.js
```

## 展示内容

1. **DAG 分组**：从单操作子图开始，展示共享写者绑定、组间环检查和短链合并。
2. **初始解构造**：回放贪心分核的评分与选择，展示候选复核结果。
3. **局部搜索**：矩阵图展示网格分块与重排、链迁移；卷积图展示子图粒度调整、生命周期调整。最后概述搜索预算、阶段顺序和接受规则。

切换用例与章节，使用“上一步 / 下一步”、方向键或“自动演示”浏览。点击图节点查看依赖；矩阵网格可点击查看对应操作链；搜索候选可切换改动前后的方案。

案例结构和成绩见 [examples](examples/README.md)。记录来自此前求解器在简化图上的运行；所选阶段覆盖这两例主起点的全部接受更新。“全部候选”仅指展示阶段的主起点候选，不代表完整搜索日志。成绩属于两核简化图，不代表仓库完整用例的性能。

`playback.js` 保存图、分组步骤、方案、评分及分块结果，用普通脚本加载以支持本地双击打开。目录不包含求解器、评测工具或数据生成脚本；复制整个 `demo/` 即可演示。网页中的源码链接指向项目的 `npu_scheduler/`，仅供阅读。
